# Bloompod — Give a Gift / Planting a Seed

Static front-end website mockup based on the approved visual structure.

## Files
- index.html — page structure/content
- styles.css — responsive styling
- script.js — filters, sorting, mobile menu, and gift modal
- assets/ — provided Bloompod/product/child images

## Run
Open `index.html` directly in a browser, or serve the folder with any static web server.

## Notes
- The gift flow is represented by a front-end modal and should be connected to the real checkout/payment flow.
- The child profiles use first names and ages in the UI. Add the final privacy/consent workflow before production.
